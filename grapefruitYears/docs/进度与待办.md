## 已知限制

- 倒计时归零时没有系统通知（小程序后台不执行代码、也无法点亮屏幕）；回到小程序才震动提示，时长按设定值记录。要准点提醒需接订阅消息（模板 ID + 定时触发器），未做。
- 「专注期间保持亮屏」默认关闭，且只在停留在专注页时有效。
- 没有邮箱验证码，用户不能自助找回密码，只能管理员重置。
- 同步是整条覆盖，不做字段级合并；墓碑不清理（可加定时云函数清半年前的）。
- 高级会员点击只弹「敬请期待」，未接支付。
- 每日提醒只保存设置项，未真正推送。
- 设置项、进行中的计时器不同步（设备级）。

## 排查过的坑（别再踩）

- `Object.assign` 会用 `undefined` 覆盖默认值 → 曾把新建项目的 id 覆盖成 undefined。store 里已用 `compact()` 过滤，启动时 `repair()` 修历史数据。
- 列表 `wx:key="id"` 遇到空/重复 id 会整页渲染报错、按钮点不动 → 全部改成 `wx:key="index"`。
- tab 页底部弹窗会被自定义 tabBar（独立图层）挡住 → 弹窗底部要留 `calc(150rpx + env(safe-area-inset-bottom))`。
- 自定义导航栏右上角会被微信胶囊遮挡 → 用 `app.globalData.capsuleRight` 留白，居中标题改绝对定位。
- 同步时间戳用严格 `>` 比较，同一毫秒的写入会被永久漏掉 → 上传/拉取都留 1 秒重叠。
- 只按 `updatedAt` 判断待上传，会漏掉「记录所属的示例项目」和「小项目的上级项目」，云端出现孤儿数据 → `dirty()` 现在保证引用完整。
- 云函数默认超时 3 秒，逐条串行读写容易超 → 改成每批 10 条并发，`config.json` 超时提到 20 秒。
