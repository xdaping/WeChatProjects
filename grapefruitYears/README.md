# 岁月 · 光阴计算（微信小程序初版）

记录自己的时间投入，帮助累积「背单词 / 练琴 / 看书 / Coding」等需要长期积累的技能。
数据全部保存在本机 `wx.storage`，无需后端。

## 5 个 Tab

| Tab | 页面 | 功能 |
| --- | --- | --- |
| 🕐 计划 | `pages/index` | 周日历切换日期；查看每个项目的今日/累计投入与目标进度；一键开始计时或手动补记；当日记录可删除；无项目时展示「10000 小时成为专家」空状态 |

## 账号（邮箱注册，微信云开发）

账号存在云开发的 `users` 集合，由 `cloudfunctions/auth` 云函数处理；**管理员在云开发控制台的数据库面板即可查看全部注册用户**。
接入步骤见 [docs/云开发接入.md](docs/云开发接入.md)（开通云开发 → 填环境 ID → 建 `users` 集合并锁权限 → 上传 `auth` 云函数）。

- 注册：邮箱 + 昵称（可留空，默认取邮箱前缀）+ 密码（≥6 位）+ 确认密码 + 勾选协议；登录：邮箱 + 密码。同一邮箱在任意设备都能登录。
- 未登录时：第五个 Tab 显示 Logo 与「注册 / 登录」按钮，计划页顶部有一条注册提示条；点头像、昵称、收件箱、升级会员都会弹窗提示去注册。
- 邮箱大小写与首尾空格会归一化；重复注册、密码错误、邮箱不存在都有对应提示。
- 密码用 scrypt + 每用户独立随机盐，只在云函数里计算，客户端和数据库里都没有明文。
- 客户端只缓存当前登录用户的公开字段（`ih_me`）用于同步渲染，进「我的」页会向云端 `me` 拉一次最新资料。

## 数据同步（本地优先 + 登录合并）

- **未登录**：项目和时间记录只存本机，功能照常可用。
- **登录/注册后**：本机数据全部上传合并，同时把云端数据拉下来 —— 换手机、删了重装，登录即恢复。
- **平时**：数据一改就触发 4 秒防抖同步；启动、回前台各同步一次；设置页可「立即同步」并显示上次同步时间。
- **冲突**：同一条数据比 `updatedAt`，谁新用谁的。**删除走墓碑**（`deleted: true`）才能同步到别的设备。
- **不同步的东西**：进行中的计时器、本机偏好设置（这些跟设备绑定）。
- 云端集合：`projects`、`records`（都按 `userId` 隔离，客户端 id 作为 `cid` 对齐），云函数 `cloudfunctions/sync`。
- 忘记密码：管理员用 `adminResetPassword`（密钥存在云函数环境变量 `ADMIN_KEY`，在控制台「云端测试」里调用）重置成临时密码，昵称/头像/会员状态都保留 —— 步骤见 [docs/云开发接入.md](docs/云开发接入.md#忘记密码管理员重置不用删账号)。

## 目录结构

```
app.js / app.json / app.wxss     全局配置与样式变量（--brand / --card / --line ...）
custom-tab-bar/                  自定义 TabBar（中间「专注」凸起按钮 + 未读角标）
utils/util.js                    日期与时长格式化（周视图、clock、human、hours）
utils/store.js                   本地数据层：项目 / 记录 / 计时器 / 设置 / 当前用户缓存 / 统计聚合
utils/account.js                 账号（云开发）：注册 / 登录 / 退出 / 同步资料 / 改密码
utils/cloud.js                   云开发初始化与云函数调用封装
utils/cloud-config.js            云开发环境 ID（需自己填）
utils/sync.js                    云同步：防抖调度、上传/拉取、登录后合并
cloudfunctions/auth/             账号云函数（scrypt 加盐哈希，openid 认身份）
cloudfunctions/sync/             同步云函数（projects / records 的 upsert 与增量拉取）
pages/                           五个 Tab + 项目编辑 + 设置
```

## 数据模型

```js
project = { id, parentId, name, icon, color, targetHours, remindOn, remindAt, createdAt, updatedAt, archived, deleted, seed }
// parentId 为空是主项目，否则是它的小项目；主项目的累计/今日时长包含旗下小项目
// 里程碑：10 / 50 / 100 / 200 / 500 / 1000 / 2000 / 5000 / 10000 小时
record  = { id, projectId, seconds, startAt, date: 'YYYY-MM-DD', note, mode: 'timer'|'manual', updatedAt, deleted }
timer   = { projectId, mode: 'up'|'down', target, startAt, accumulated, paused }
users 集合（云端）= { _id, email, nickName, avatar, pro, inbox, salt, hash, openids[], createdAt, lastLoginAt }
本地缓存 ih_me     = { id, email, nickName, avatar, pro, inbox }   // 只有公开字段
```

计时器状态写入 storage 并以时间戳计算，切页面、退到后台或重启小程序后仍能继续。

## 运行

1. 微信开发者工具 → 导入项目，选择本目录（AppID 已写在 `project.config.json`）。
1. 要用账号功能：按 [docs/云开发接入.md](docs/云开发接入.md) 开通云开发、填环境 ID、部署 `auth` 云函数。
2. 首次启动会自动创建 4 个示例项目（背单词/练琴/看书/Coding），无记录。
3. 想看统计效果：我的 → 设置 → 「载入示例数据（近 90 天）」。

## 已知限制（初版）

- 每日提醒目前只保存设置项：小程序无法本地推送，正式版需接入微信订阅消息（模板 ID + `wx.requestSubscribeMessage` + 服务端定时下发）。
- 环境音只保存选择结果，未内置音频文件。
- 高级会员为本地体验开关，未接入支付。
- 账号已上云，但**没有邮箱验证码**，也不能自助找回密码（需再接邮件服务）。
- 同步是「后写入者胜」，没有字段级合并：两台设备同时改同一个项目的不同字段，会以整条较新的为准。
- 云开发未配置时，时间记录功能照常可用，只有账号相关操作会提示去填环境 ID / 部署云函数。
- 倒计时归零时**不会有系统通知**：小程序在后台不执行代码，也无法点亮屏幕。回到小程序时才震动提示，但时长按设定值记录、不会少记。要做到准点提醒需接微信订阅消息（模板 ID + 云函数定时触发器）。
- 图标使用 emoji，未使用图片资源。
